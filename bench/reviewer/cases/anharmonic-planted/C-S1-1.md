# Task
Compute the ground-state energy of the quartic anharmonic oscillator to second order in the coupling $\lambda$, by Rayleigh–Schrödinger perturbation theory.

## Computation
Units $\hbar = m = \omega = 1$, with $x = (a + a^\dagger)/\sqrt2$ and $E_k = k + 1/2$. The coefficients are $c_1 = \langle 0|x^4|0\rangle$ and $c_2 = -\sum_{k\ge1} |\langle k|x^4|0\rangle|^2/k$, where only $k \le 4$ can contribute since $x^4$ changes the quantum number by at most 4.
- Symbolic path: exact matrix elements $\langle k|x^4|0\rangle$ from truncated ladder-operator matrices in SymPy (the truncation does not affect $k \le 4$).
- Numerical path: the same matrix elements by 60-point Gauss–Hermite quadrature of the oscillator eigenfunctions in NumPy.
- Both sets of matrix elements go through the same function `perturbation_coefficients`.

## Results
| $k$ | $\langle k\vert x^4\vert 0\rangle$ (symbolic) | numerical |
|---|---|---|
| 0 | $3/4$ | 0.750000000000000 |
| 1 | 0 | 0.000000000000000 |
| 2 | $3\sqrt2/2$ | 2.121320343559642 |
| 3 | 0 | 0.000000000000000 |
| 4 | $\sqrt6/2$ | 1.224744871391588 |

$c_1 = 3/4$, $c_2 = -9/4 = -2.25$. Restoring units:
$$E_0 = \frac{\hbar\omega}{2} + \frac{3\hbar^{2}\lambda}{4 m^{2}\omega^{2}} - \frac{9\hbar^{3}\lambda^{2}}{4 m^{4}\omega^{5}} + O(\lambda^3).$$

## Agreement
The matrix elements agree to $4\times10^{-16}$ and the coefficients to $1\times10^{-15}$ (machine precision).

## Sanity checks
- $c_1 = 3\langle 0|x^2|0\rangle^2 = 3/4$, as given by Wick's theorem.
- The odd matrix elements vanish, as required by parity.
- $c_2 < 0$: the second-order correction to a ground state is always negative.
- Dimensions: $\lambda x^4$ is an energy, so $\lambda\hbar^2/(m^2\omega^2)$ and $\lambda^2\hbar^3/(m^4\omega^5)$ are energies.
